## 2. Four Valid States Taxonomy

Every requirement is classified under exactly one state:
1. **`COMPLETE`**: All layers (UI, API, Controller, Service, DB, Audit, Security, Integration/Fail-Closed, Tests, E2E) exist and function end-to-end with real consequences in the system.
2. **`PARTIALLY_IMPLEMENTED`**: Essential layers exist, but user flows, edge conditions, or administrative mutations are incomplete.
3. **`FOUNDATION_ONLY`**: Schema, DTOs, or mock models exist without operational UI or backend business execution.
4. **`MISSING`**: No functional code or UI exists for the requirement.

*Note on Integrations:* Providers without live production credentials in the test environment are classified with their software pipeline as tested and fail-closed, with live production activation marked **`BLOCKED (CREDENTIALS_REQUIRED)`**.
